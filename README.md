## 📖 Sobre

Este projeto tem como objetivo fornecer uma website inspirada na era clássica do Metin2, trazendo uma experiência visual nostálgica semelhante aos websites antigos utilizados entre 2006–2010.

Ideal para:

- Servidores Old School
- Servidores PvM/PvP Clássicos
- Projetos Nostalgia
- Private Servers Metin2
- Sistemas personalizados

A comunidade old-school normalmente busca preservar a experiência clássica sem excesso de sistemas modernos. :contentReference[oaicite:0]{index=0}

## 🚀 Instalação

### 1. Clone o repositório

```bash
git clone <repo-url>
```

### 2. Faça upload dos arquivos

Envie todos os arquivos para:

```text
public_html/
```

ou

```text
www/
```

### 3. Configure o banco de dados

Edite os arquivos responsáveis pela conexão.

Exemplo:

```php
host=localhost
database=metin2
username=root
password=*****
```

### 4. Permissões

Garanta permissões corretas:

```bash
chmod -R 755 .
```

### 5. Acesse

```text
http://localhost/
```

ou

```text
https://seudominio.com
```
